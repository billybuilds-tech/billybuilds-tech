## 🚀 Featured project — Online Blood Banking System

A web platform that connects blood **donors, recipients, blood banks and a Blood Bank Manager** across Tanzania
(Final Year Project, IFM 2025/2026).

- 🩸 Live blood stock across banks, with ABO/Rh compatibility search
- 🏥 Donor health screening, deferrals and blood-group confirmation by the blood bank
- 📣 Urgent appeals that reach only the donors who can donate today
- 🔄 Inter-bank transfers inside database transactions, so units are never lost or counted twice
- 🔔 Real-time notifications · 🇹🇿 English and Swahili
- ✅ 21 unit tests, 40 API tests, load-tested with 25 concurrent users

**Stack:** React 19 · Node.js / Express · MySQL · JWT · Server-Sent Events
